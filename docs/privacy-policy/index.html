3. Local On-Device Processing (Privacy Core)

AI PDF Toolkit is built with a strict local-first architecture. The vast majority of operations execute entirely within the application sandbox on your local device without internet access:

  • Visual PDF Redaction: Allows users to draw blackout redaction boxes over sensitive text or graphics. Redactions are burned irreversibly into the document structure locally.
  • Document Encryption & Protection: Generates AES/standard PDF password protection with separate User and Owner passwords and permission controls (printing, content copying) 100% locally.
  • Digital Signatures & Stamps: Captures signatures and places visual stamps with local canvas rendering; flattened directly onto the target PDF.
  • PDF Form Filler: Allows interactive filling of PDF forms directly on your device.
  • Merge & Split PDF: Combines multiple PDFs or extracts selected page ranges entirely within local device memory.
  • Compress PDF: Optimizes stream dictionaries, fonts, and raster images on-device to minimize file size.
  • Rotate & Organize Pages: Reorders, deletes, and rotates PDF pages locally.
  • Watermark PDF: Overlays customizable text or visual watermarks on-device.
  • Format Conversions: Text to PDF, Markdown to PDF, PDF to Text, PDF to Image, and Images to PDF execute locally without cloud APIs.
  • Camera Document Scanner: Captures document photographs, performs perspective correction, and generates multi-page PDFs entirely on-device.

Zero Cloud Document Storage: We do not operate any proprietary servers or cloud document vaults. Your original, edited, and generated files remain exclusively on your device unless you choose to share them via your operating system's standard share sheet.

4. AI Features & Cloud Transmission Protocols

AI PDF Toolkit provides optional generative AI capabilities, including Chat with PDF, AI Summarizer (Executive Brief & Action Items), AI Refine, and AI to PDF.

What Data is Transmitted

When and only when you explicitly tap to execute an AI command or submit a prompt:

  • User Prompts: The text instructions, queries, or customization options you input.
  • Extracted Document Text: Text extracted locally from the pages you choose to analyze is transmitted as contextual input to the AI model.
  • Active Conversation History: In multi-turn chat sessions, recent turn history within the current session is provided to maintain context.

What Data is NEVER Transmitted

  • No Binary Files: Binary PDF files, document byte arrays, scanned photos, and local file paths are never transmitted. Only extracted plain text is sent.
  • No Unselected Files: Documents or images on your device that you have not opened or specifically queried are never read or transmitted.
  • No User Identification: We do not attach names, emails, phone numbers, advertising IDs, or device hardware fingerprints to AI requests.

Configured AI Service Providers

Outbound AI calls are routed over TLS 1.3 encrypted HTTPS to the following trusted endpoints:

  • Primary AI Provider — Google Gemini API (Google LLC):
    Endpoint: https://generativelanguage.googleapis.com
    Data sent to Google Gemini is processed according to Google's Enterprise Developer Terms and the Google Privacy Policy. User data transmitted via API calls is not used to train Google foundational models.
  • Fallback AI Provider — Hugging Face Inference API (Hugging Face, Inc.):
    Endpoint: https://api-inference.huggingface.co
    Used solely as a secondary fallback if the primary API is unavailable. Data is processed per the Hugging Face Privacy Policy.

RAM-Only Ephemeral AI Memory

In-app AI chat exchanges and reasoning traces exist strictly in volatile runtime memory (RAM) during your active screen session. All conversational context is wiped immediately when you navigate away from the chat screen, switch tools, or close the application.

5. Redaction, Encryption & Document Security

AI PDF Toolkit contains specialized features engineered to protect user privacy and sensitive documents:

  • Irreversible Redaction: When you redact sensitive data (such as social security numbers, bank details, or confidential text), the Application removes underlying vector elements and burns opaque rectangles into the page canvas. The redacted text is destroyed and cannot be recovered via text selection or PDF decompilation.
  • Standard PDF Cryptography: Document password encryption adheres to ISO 32000 standard PDF security specifications. User passwords encrypt file reading; Owner passwords protect modification permissions. Passwords are never saved in logs, metadata, or sent over any network.
  • Local Document Sandboxing: Decrypted working copies exist solely within application-private internal cache folders, which are cleared upon task completion.

6. Device Permissions & Hardware Access

The Application requests only the minimal system permissions required to execute user-requested tasks:

  • Camera (android.permission.CAMERA):
    Requested only when you launch the Camera Document Scanner to photograph physical pages. Camera feeds are processed in real-time on your screen and are never activated in the background.
  • Photo & Media Picker (READ_MEDIA_IMAGES, READ_MEDIA_VISUAL_USER_SELECTED):
    On Android 13 and Android 14+, the app uses the system-standard Photo Picker. You grant access only to the individual images you specifically select for document conversion.
  • Legacy Storage Access (READ_EXTERNAL_STORAGE, WRITE_EXTERNAL_STORAGE):
    Restricted to devices running Android 9 (API 28) and Android 10 (API 29) to permit saving and opening PDFs from user-selected directories. Not requested on modern Android versions utilizing Scoped Storage.
  • Internet Access (android.permission.INTERNET):
    Used exclusively to send encrypted HTTPS requests to configured AI providers when you trigger AI features, and to launch external browser links (such as this Privacy Policy).

7. Local Storage, Retention & Deletion Controls

AI PDF Toolkit utilizes an embedded on-device database (Hive) to store your document creation history.

Stored Metadata

Each history item contains only local operational metadata:

  • A randomly generated local UUID identifier
  • Document title / filename
  • Creation date & timestamp
  • Absolute on-device file path
  • Tool type identifier (e.g., redaction, merge, ai_notes, scanner)

User Deletion Controls

  • Single Record Deletion: Tap the delete icon next to any history entry to instantly purge the database record and delete the associated file from device storage.
  • One-Tap Complete Wipe: Navigate to Settings → Clear History to wipe all history records in one click.
  • Automatic Temporary Cleanup: The application automatically detects and deletes orphaned intermediate files upon launch.
  • Uninstall Deletion: Uninstalling the Application completely and permanently deletes all database boxes, configuration keys, and private cache files.

8. Third-Party Services, SDKs & Ads

Our codebase contains no surveillance code or data brokers:

  • No Tracking Analytics: There is no Google Analytics for Firebase, Flurry, AppsFlyer, Adjust, or Mixpanel SDK present in the application.
  • No Crash Telemetry Uploads: Crash logs remain on-device or within the standard operating system bug report tools provided by Google Play Console.
  • No Third-Party Ad Networks: We do not embed AdMob, Meta Audience Network, Unity Ads, or programmatic ad exchanges. Rewarded feature tokens run on local, private application timers.
  • System Sharing: We utilize share_plus to invoke Android's native system share dialog. Data is passed directly to the app you select (e.g. Gmail, Drive, WhatsApp) without passing through intermediary servers.

AI PDF Toolkit is a general utility productivity application. It does not target, collect personal information from, or profile children under the age of 13 (or under 16 in the EEA/UK), in accordance with the Children's Online Privacy Protection Act (COPPA) and General Data Protection Regulation (GDPR).

Because no account registration, persistent user profiling, or personal identification exists within the Application, no children's data is acquired or retained.

10. Data Security Architecture

We safeguard your data through robust architectural choices:

  • HTTPS / TLS 1.3 Encryption: All outbound AI network traffic is strictly encrypted using modern Transport Layer Security protocols.
  • Application Sandbox Isolation: Processed PDFs and local database files are contained within private application storage protected by Android's Linux kernel process isolation.
  • Zero Plaintext Secret Exposure: API credentials and configuration variables are bundled securely within compiled code and environment configurations, never logged or displayed.

11. User Rights & Regulatory Compliance

In compliance with global data protection frameworks (including GDPR, UK-GDPR, CCPA/CPRA, and LGPD):

  • Right to Access & Portability: All your documents and history records are stored directly on your phone and can be opened, inspected, exported, or transferred at any time.
  • Right to Erasure: You can delete any or all documents and history records directly within the app or by clearing app data in Android Settings.
  • Right to Restrict Processing: You can use standard PDF tools completely offline in Airplane Mode without network connectivity.
  • No Sale or Sharing of Personal Data: We do not sell, rent, trade, or monetize your personal data or document contents under any circumstances.
