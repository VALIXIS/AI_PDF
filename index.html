1. Introduction & Developer Identity

This Privacy Policy describes how AI PDF Maker (referred to as "the Application", "we", "us", or "our", also identified as PDF AI Toolkit in repository sources and package com.nagas.pdfaitoolkit), developed and maintained by metspy9069, handles user data, device permissions, local document manipulation, and AI-assisted capabilities.

We are committed to user privacy and data minimization. This policy is written with complete factual fidelity to the actual application implementation. We do not engage in covert tracking, unwanted data harvesting, or undisclosed cloud transmission.

3. Local On-Device Processing

AI PDF Maker is built with a local-first architecture. The standard document operations implemented in the application run entirely within the application sandbox on your local device:

  • Merge PDF: Combines multiple PDF files selected by the user into a single document on-device.
  • Split PDF: Extracts specified page ranges from a PDF on-device.
  • Compress PDF: Optimizes internal PDF content streams and image resolutions on-device.
  • Rotate PDF: Rotates document pages (90°, 180°, 270°) on-device.
  • Watermark PDF: Embeds text watermarks on document pages on-device.
  • Protect PDF: Applies standard encryption and password protection on-device.
  • PDF Editor & Annotation: Allows adding text notes, freehand drawings, and visual highlights locally.
  • Text to PDF & Markdown to PDF: Formats and renders plain text or markdown files into PDF documents locally.
  • PDF to Text: Extracts text content from PDF pages locally on-device.
  • PDF to Image & JPG to PDF: Renders PDF pages as images or bundles user-selected photos into PDF files locally.
  • Document Scanner: Captures physical documents via camera or gallery and compiles them into PDF files locally.

Zero Cloud Document Storage: We do not operate any proprietary server or cloud storage for user documents. Your original and processed files remain exclusively on your device unless you explicitly share them via the system share menu.

4. AI Data Processing & Third-Party AI Services

AI PDF Maker provides optional generative AI capabilities, including AI to PDF (Study Notes, Summary, Text Cleaning), AI Refine, Chat with PDF, and Multi-Document Comparison.

What Data is Transmitted

When you explicitly initiate an AI operation or send a message in the AI Companion chat:

  • User Prompts: The text instructions or questions you submit.
  • Extracted Document Text: When using document Q&A, summary, or comparison features, text extracted locally from your chosen document(s) is sent as context for the AI model to generate an answer.
  • Session Context: The active in-memory conversation history (limited to recent turns) to provide context for follow-up questions.

What Data is NOT Transmitted

  • No Binary Files: Binary PDF files, DOCX files, raw scanned image bytes, and file system paths are not uploaded to AI services. Only the extracted textual content is transmitted.
  • No Unselected Files: Files on your device that you did not specifically open or attach are never accessed or transmitted.
  • No Personal Identifiers: Your device identifiers, IP address associations, location data, or contact lists are not collected or transmitted by our application logic.

Configured AI Providers

The application communicates directly over secure HTTPS with the following configured AI service providers:

  • Primary AI Provider — Google Gemini API (Google LLC):
    Endpoint: https://generativelanguage.googleapis.com
    Models: Gemini Flash series.
    Data sent to Google Gemini is governed by Google's developer terms and Google Privacy Policy.
  • Fallback AI Provider — Hugging Face Inference API (Hugging Face, Inc.):
    Endpoint: https://api-inference.huggingface.co
    Used as a resilient fallback when Gemini is unavailable or not configured.
    Data sent to Hugging Face is governed by the Hugging Face Privacy Policy.

Ephemeral AI Chat Retention

In-app AI chat interactions and conversations exist strictly in volatile runtime memory (RAM) within the active screen session. Chat messages and conversation histories are discarded immediately when you navigate away from the chat screen or close the application. We do not persist AI conversations in local database storage or on remote servers.

5. Device Permissions

The Application requests only the minimal permissions necessary to perform its core functions:

  • Camera (android.permission.CAMERA):
    Required only if you use the Document Scanner or photo capture feature to photograph physical documents. The camera is accessed strictly in real-time when actively taking pictures; it is never accessed in the background.
  • Storage & Media Access (READ_EXTERNAL_STORAGE / READ_MEDIA_IMAGES):
    Used through the platform-standard file picker and image picker to allow you to select specific PDF documents, text files, or images you wish to process, convert, or view. The app only accesses files explicitly chosen by you.
  • Internet Access:
    Required exclusively to transmit HTTPS API requests to the configured AI providers when you invoke AI features, and to open external web links (such as this Privacy Policy) in your default web browser.

6. Local Storage, Retention & Deletion

AI PDF Maker utilizes an on-device embedded database (Hive) to maintain a local record of documents you create or process within the app.

What Metadata is Stored

The local history box (historyBox) contains entries consisting of:

  • A unique local entry identifier (UUID)
  • Document title / filename
  • Creation timestamp
  • Local file path on device storage
  • Tool type identifier (e.g., ai_notes, merge, split, scanner)

Data Deletion Controls

  • Individual Item Deletion: You can delete any history item from the History screen at any time. Deleting a record also removes the associated generated file from disk.
  • One-Tap History Clear: You can wipe all history records at once by navigating to Settings → Clear History.
  • Temporary File Cleanup: The application automatically detects and deletes orphaned temporary working files (e.g., intermediate atomic operation files) during routine app startup and cleanup cycles.
  • Complete App Data Removal: Clearing the application's storage in your device settings or uninstalling the app permanently erases all local database records, preferences, and cached working files.

8. Children's Privacy

AI PDF Maker is a general-audience productivity utility and does not knowingly collect, store, or solicit personal information from children under the age of 13 (or under the applicable age of consent in your jurisdiction).

Because the Application does not maintain user accounts, require registration, collect personal profiles, or track user identities, no personal data from children is harvested. You may contact us at the address below with any questions.

9. Data Security

We implement industry-standard technical measures to protect your data:

  • Encrypted HTTPS/TLS: All outbound network transmissions to AI service providers are strictly conducted over HTTPS (TLS 1.2/1.3) to prevent eavesdropping and man-in-the-middle attacks.
  • Local Sandbox Isolation: All on-device file manipulation and Hive database operations execute within the protected operating system application sandbox.
  • No Plaintext Key Exposure: Application API keys and environment configurations are managed through protected configuration files and are never exposed in user-accessible UI screens.

10. User Rights & Data Control

Because all document processing and history storage are strictly localized to your device:

  • You have direct and total control over your files and history records.
  • You can inspect, export, share, or permanently delete your files at any time without submitting a data deletion request to a remote server.
  • You can revoke Camera or Storage permissions at any time via your device's operating system settings.
